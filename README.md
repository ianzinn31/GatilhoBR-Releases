# GatilhoBR PRO — Instalador Oficial da Extensão

Canal oficial de distribuição do pacote instalador da extensão **GatilhoBR PRO**.

> Este repositório contém **exclusivamente pacotes compilados e criptografados** em GitHub Releases. Nenhum código-fonte é armazenado aqui.

## Download Direto (Última Versão)

- **Instalador Oficial (.ZIP):** [GatilhoBR-Extensao-Instalador.zip](https://github.com/ianzinn31/GatilhoBR-Releases/releases/latest/download/GatilhoBR-Extensao-Instalador.zip)
- **Versão atual publicada:** `v4.3.14`

## Como Instalar no Navegador (Chrome / Edge / Brave)

1. Baixe e extraia o arquivo **`GatilhoBR-Extensao-Instalador.zip`**.
2. Execute **`Instalar-Extensao.bat`** (ou abra `chrome://extensions` e ative o **Modo do desenvolvedor**).
3. Clique em **"Carregar sem compactação"** e selecione a subpasta **`extensao`** dentro do pacote extraído.

Para instruções visuais detalhadas, abra o arquivo `COMO-INSTALAR.html` incluído no pacote.
